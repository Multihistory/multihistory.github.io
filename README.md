# Multi-History Science

An independent research collaboration on rewrite systems, hypergraphs, causality and emergent spacetime.

Website: https://multihistory.github.io/

## Development

Use Node 22.12 or newer.

```sh
npm ci
npm run dev
npm run build
```

Content lives in `src/data/`. Read [AGENTS.md](AGENTS.md) before editing.
Pushes to `main` deploy through GitHub Pages.
